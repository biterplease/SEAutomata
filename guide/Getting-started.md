# Network

In order for the Automata blocks to communicate, they need to be "In network", this means that the grids with the Automata blocks should either:
- Be within antenna range of each other, OR
- Be connected via laser antennas

Drones can communicate with the grid they are docked on, but they operate better if they have antennas. The range can be as small as you'd like, as long as they can reach the grid they need to communicate with.

I recommend 200m for both static grids and drones, and using laser antennas for long-range static grid networks.

Initially, a single grid with all 5 computers, and a single drone of each type, is enough to start automating.
